# DSH 3.x source archive

The 2026-10-19 repository transition preserved 27 additional archive branches: seven source snapshots and 20 previously local branch tips. Every archive branch was read back from GitHub and matched its fixed commit. All 234 pre-existing remote branches and all 191 tags matched the pre-transition inventory at that check. The existing pull requests and Releases are retained; this transition does not merge or close them.

DSH 3.x development is frozen by the selected project policy. This is not a GitHub repository archive or a new branch-protection setting. The original branches remain available, and V4 does not import, merge, or vendor their source. Build output, dependencies, local scratch files, credentials, and runtime data are not part of the new source snapshots.

## Verification scope

The archive preserves unfinished source as well as completed work. It is not a release, an installed-app result, or evidence of model quality or RLM benefit. The root snapshot passed the normal pre-push typecheck, including its required build and client compiler checks. The WP1 snapshot passed its full typecheck. The affected browser test passed 24 cases, and the saved Gouzi audit test passed two cases. These results cover their own inputs; they are not a full acceptance of all seven snapshots.

The WP1 documentation gate reported **24 passed and four failed**: Cordis catalog freshness, config catalog validation (12 violations), persistence catalog freshness, and config source ownership (two fixture endpoint literals). Those failures remain recorded. This archival task does not resume the cancelled 3.x development or repair its unfinished features. No real-model tests, paid experiments, release builds, or installations were run for this transition.
