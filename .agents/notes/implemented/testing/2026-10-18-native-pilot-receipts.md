# Agent Note: Native fake pilot receipts

Status: implemented

English | [中文](2026-10-18-native-pilot-receipts.zh.md)

## Problem

Handwritten outputs cannot prove that a scheduled comparison used the actual Worker, complete material or Runtime child results. Final text alone can hide an unresolved request or failed cell.

## Decision

The assembled keyless Consumer uses the existing Loader, common Worker tool loop, Runtime and evaluation ledger. Context placement and Host-owned spawn policy remain independent. A complete map/reduce trial sends every original chunk to its map Worker and passes each complete, owner-authorized child result into the root's next model request. All arms retain the same caps and complete source bytes. External-context fixture cells explicitly request an initial 64-byte fragment; they do not claim to read the full corpus.

An independent Python reader binds request bytes, attempts, sends, Worker commands and durable Runtime results. It derives lifecycle and final raw text from observations before calling the existing official controller scorer. Unknown requests retain their reservation and an explicit exclusion from terminal grading. Missing executions stay missing. Validation and output creation do not execute or retry a trial.

## Alternatives considered

Handwritten terminal outputs test the scorer but do not verify execution. Grading directly inside the Worker would expose controller-only answers and combine independent responsibilities. The Consumer therefore retains observations, and a separate read-only controller validates them before scoring.

## Consequences

The adapter is scripted and in process. Its request/usage records test integration and accounting relationships, not model quality, physical HTTP, token upper bounds or cost. Receipt hashes are not signatures from an independent observer. Complete artifacts remain local, and scorer reports contain controller-only gold. Neither successful source/built fixtures nor a scheduled fake run grants paid launch, external research, packaging or installation authority. Mutation tests reject missing, duplicated or inconsistent request and child-result observations without replaying their Worker executions.
