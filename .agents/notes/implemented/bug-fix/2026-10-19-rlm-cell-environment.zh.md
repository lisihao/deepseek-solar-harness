# Agent Note: RLM cell 环境

Status: implemented

[English](2026-10-19-rlm-cell-environment.md) | 中文

## 问题

生成的 REPL 代码在 Worker 中运行，可以检查自身进程的环境。继承 daemon 环境会暴露与任务无关的配置，包括通过环境变量提供给 daemon 的模型提供方认证信息。

## 决定

本地 RLM kernel 创建每个 Worker 时都传入空环境。新会话、child 和源码恢复使用相同的创建方式。任务输入仍是显式运行时上下文；特权操作仍通过 Host binding 提供。环境规则固定，不提供继承 daemon 环境的部署选项。

## 考虑过的替代方案

**按名称过滤敏感变量。** 拒绝列表仍保留名称未体现内容的环境变量。空环境避免依赖这些命名约定。

**只修改实验启动器。** 启动器专用的环境不覆盖其他消费方创建的 cell，也不覆盖通过实际 Runtime 执行的声明源码恢复。

## 后果

依赖环境配置的 cell 必须显式接收所需任务数据。单元检查覆盖新 Worker 和恢复的 Worker，并验证 cell 修改自身环境不会改变宿主环境。不加载模型提供方的纯运行时 Loader 快照覆盖根、child 和 Provider 重启。这不是操作系统沙箱：文件访问、凭据文件、原生进程能力和网络访问仍须分别控制；此改动不证明实验已经就绪，也不证明 RLM 收益。
