# Agent Note: ChatGPT Web 顾问与主控路径

Status: rejected — Web 主控路径已删除（[删除说明](../../implemented/feature/2026-09-26-remove-chatgpt-web-tool-coordination.md)）；顾问路径和目录刷新不依赖它，已单独交付

[English](2026-09-23-chatgpt-web-coordination.md) | 中文

## Problem

主模型选择和下游物理算子偏好表示不同角色。任务提到 ChatGPT 时替换已选定的代码主控，会丢失实施与验收的责任归属。反过来，仅在界面解锁协作选项，也不能让纯文本 ChatGPT Provider 获得 DSH 工具协调能力。

## Proposal

保留三条路径：API／原生主控将有界规划或研究任务委派给临时 Web 算子；独立 Web 调用保持纯文本行为；本地配置后的 Web 主控通过现有 DSH 归属方本地执行桥使用真实 MCP 工具。当前捕获的模型选择拥有主路由，协作偏好指导委派而不替换主模型。

Web 主控要求显式配置 ChatGPT 自定义 MCP 应用。本地回环 MCP 端点使用持久随机路径和用户配置的隧道。每次 MCP 请求的原生请求 ID 必须匹配确切归属网页回合中观察到的元数据，才能返回 DSH 工具定义或执行权限。身份缺失、歧义或撤销均拒绝执行。不接受模型生成的身份凭据或提示词编码的伪工具协议。

Provider 拥有持久网页会话及每条命令的发送／结果回执。重启恢复核对已有回合，不重放发送结果不确定的请求。活动命令保留取消归属，并在确认完成前等待尚未返回的工具结果。现有 DSH 工具管线继续负责权限、持久工具回执、编排和验收。独立调用不获得这些权限。

本地设置界面区分独立模式、已配置协作以及最近一次已证明工具调用的时间。配置开关不能证明连接器当前可用。模型和推理档位仅在网站可观察时报告。

## Catalog refresh

模型目录来自已配置 API 的 `/models`、原生订阅发现和已认证的 Web 模型控件。显式刷新保留主模型选择，失败时保留上一次成功数据。新标识仅具有适配器已支持的能力；目录项本身不能启用不支持的模态或推理控件。Web 推理偏好使用独立 Session 事件，使用前根据当前模型可见控件验证。

## Alternatives considered

**替换 Ego 或安装第二套 Agent 应用。** 这会重复浏览器和任务归属。现有浏览器 Provider 继续承担操作，Chat On Steroids 为请求归属、持久续接和可见恢复状态提供参考。

**将助手文本解析为本地工具命令。** 这会伪装工具连接、违反物理算子桥规则，并混淆普通建议与已授权操作。

**立即解锁所有组合。** 这会向纯文本 Provider 宣称本地执行能力。界面选项依据实际配置的执行模式开放，后端准入仍执行权限规则。

## Acceptance criteria

真实组合示例保留 API 或原生主控，由 Web 顾问返回方案，依赖它的实施和测试步骤保留各自算子身份。独立 Web 请求不能触发无关原生产品资格检查。已配置的 Web 主控通过 MCP 使用真实 DSH 工具，并将实际结果记录到正确 Session。跨会话请求证据、过期调用、未公开工具、发送结果不确定和用户停止均不能触发重放或成功完成。

续接、排队纠偏、压缩交接和结束检查必须保留当前目标及已记录的模型可见上下文。无密钥示例覆盖组合协议，账号验收单独证明 ChatGPT 自定义应用挂载和真实工具结果。源码、制品、安装版本及远端提交一致后，Desktop 交付才算完成。

## Risks

ChatGPT 页面内部实现变化可能导致无法观察身份或完成状态。此类失败必须明确呈现，同时保留独立路径。自定义应用和隧道可用性依赖用户账号配置。源码测试不能证明浏览器兼容性、订阅可用性或性能提升。
