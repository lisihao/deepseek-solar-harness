# dsh-rlm-strategy-local

[English](README.md) | 中文

确定性的基础 RLM Provider。自动模式结合任务/阶段信号与用户选择的质量、速度、经济或综合目标；显式选择标准模式或 RLM 始终优先。策略 `1.3.0` 采用 Prime 的一层递归默认值，为并行叶子分配刻意不同的分析镜头，并要求覆盖检查式综合，避免把重复叶子误当成质量增益。

本包同时提供不调用模型的质量评测契约。可复用的盲测 fixture 为每个案例保存两个匿名分臂，独立 reveal-key 文件只在输出冻结后才把分臂映射为 direct 与 RLM。日常开发只评测已记录 fixture，不调用模型；报告会把人工和无密钥证据标为 `fixture-regression-passed`，不得据此声称真实质量提升。只有带来源记录且通过的 `real-subscription` 盲测才会报告 `measured-lift-passed`。一个发布候选最多执行一次获准的真实订阅盲测。

## 模型体验

本 Provider 通过应用到选中节点的有界递归计划间接影响模型。

#### KV 缓存影响

启用递归会将有界指令加入已封存节点请求，并改变其请求前缀。

## 已知限制与后续工作

- 基础实现使用确定性的任务、阶段和优化目标信号，而不是语义分类或未经验证的质量承诺。
- 最大深度、子节点数和 Turn 数是固定安全上限，不是自适应预算。
- RLM 是质量假设，不保证必然提升；自动策略必须保留评测证据，在没有实测增益时可以继续直接执行。
- 确定性评分器检查明确的验收事实和预算边界；开放式写作质量仍需独立的人类或模型评审。
