# @deepseek-ai/dsh-research-handoff

[English](README.md) | 中文

私有 Service Definition 区分当前嵌入 Host 的访问能力、显式注册的平台 Driver 和留存的研究数据。researchHandoff 服务不允许模型或通用 RPC 调用者注册 Host。同一进程的可信插件与嵌入 Host 共享信任域。

## 当前 Host 与精确动作

Host 显式注册所有者、工作区、来源配置摘要、目标、Driver 选择、判断输入通道、策略版本及完整输入字节上限。可调用能力随注册失效。保存的所有者 ID、确认、摘要或导入策略不能重建该能力。选择包含模型、模式、请求的推理力度及工具；推理力度区分必须满足、未请求和不适用，与实际界面未观察到控件分别记录。

每个动作保留完整确认绑定、原目标、Driver、选择、全部输入，以及明确的准备提示词身份；直接 Host 文本显式使用 null。Host 可以准备和读取完整版本化提示词，这不提交输入，也不确认 run。Driver 资格检查在持久化 unknown 意图之后运行。执行 Driver 必须在内部等待结束后、不可逆提交之前立即调用提供的检查函数。资格与回执绑定完整动作摘要。中止属于本地证据，不能证明远端取消。

原目标保持不变。观察到的接纳证据可以关联新分配的会话和报告。每个非空资源身份不能替换；尚未分配的身份可以通过同一动作的后续观察补齐。观测使用该留存关联，不为解决不确定性另开任务。

Host 可以为归属明确的 run 领取唯一规范流程，并用显式只读采集器采集已完成原阶段的输出。观察身份、完整字节及产物版本在同一事务中留存；相同观察幂等读取，变化的观察追加新版本。采集器必须在读取前及内部等待后调用当前访问检查。撤销阻止新读取，已经接纳的调用返回的迟到事实仍归原动作。[流程 Consumer](../research-workflow/README.md) 提供当前 Agent 桥接与标准协调器，网站传输另行实现。

可选的可信生命周期 scope 在持久读取和既有外部操作 guard 之前复查嵌入所有者；回调返回后，Provider 再检查同一 grant 仍然有效。该可调用检查与导入策略数据分开，不提供它的原始 Host 注册仍保留底层行为。流程 Consumer 负责安装实际 Agent/Session 关联。

## 来源 Reader 访问

Host 可显式提供当前来源能力，列出允许的 Reader ID，并提供有归属的 URL 授权回调。缺少该能力时不能执行来源读取。Reader 必须在异步准备后、首次访问和每次跟随重定向前立即调用同步检查；不能满足此条件的适配器必须在访问前拒绝。Provider 检查当前注册、修订和确认。这是同一进程中可信适配器必须遵守的条件，不证明现有浏览器传输能够拦截重定向。

来源请求和实际捕获与语义引用判断分别记录。没有关联资源的未知读取不能通过重新打开 URL 恢复。按 owner 授权后的持久读取保留全部提供的 UTF-8 提取正文、元数据空值、独立读取范围和原请求摘要；来源观察本身不表示研究核验完成。

## 工作流记录

来源捕获分别记录读取范围与 complete、partial、unknown 完整性；不完整或未知时必须保留限制说明，正文摘要不能替代该状态。run 修订不会单独阻止观察已关联的原资源，但观察仍检查当前 Host、Reader、来源配置和原目标授权；它不打开新页面，也不重新读取原 URL。

引用判断绑定精确目录摘要、当前论断文本摘要、原来源读取和规范化观察摘要。非空短引必须逐字节匹配留存全文或相关原文段中的完整 UTF-8 区间；仅 URL、搜索摘要或标题不能满足实际原文要求。捕获完整性仍独立，后续完成逻辑必须另外检查。引用关系、来源家族依赖和原始权威记录的分类仍是有归属判断；声明的模型或人工作者与当前 Host 的实际输入通道分别记录。响应以追加方式保留，不能删除反证；该记录不产生独立支持计数、事实正确保证或核验完成标志。

反证处置绑定原 Citation 或材料判断的完整记录摘要、历史目录和论断文本。针对同一原目标的处理以 CAS 追加，保留所有历史，允许明确重新保留未解决状态；追加另一条 supported 引用不会改变处置。explained 需要实际 Citation；corrected-in-final 使用 Citation 或明确的 finalCorrection 映射依据，仍属于有归属解释，不是自动语义裁定。声明的作者与当前 Host 输入通道分别持久化；导入完成字段不能授权或解决反证。处置记录本身不提供最终报告映射或当前核验完成状态。

最终映射保留精确的最新两阶段报告身份、完整最终 UTF-8 正文、当前候选文本摘要、报告字节位置和无环依赖图。历史关键论断的纠正与删除必须有明确谱系及报告修订位置，无替代项的删除也不例外。当前 Host 另行确认精确映射和候选分母；新映射、报告、目录或 run 修订使当前确认失效。导入的确认与完成字段被排除。分类、来源评估、反证检查范围及语义充分性仍是有归属解释；映射确认不计算核验完成状态。

finalCorrection 只用于精确历史目标的 corrected-in-final 撤回依据。追加与当前已确认映射的校验在同一事务内进行，必须匹配 retired 的目录版本、claimId、原文摘要及报告修订位置，最终所有 adopted-fact 均不能继续采用该原文摘要。映射先存在，处置随后追加；当前映射不必反向列出新处置 ID。历史读取保留固定映射关联，新映射或报告之后不能把旧撤回依据当作当前依据，也不回退到无关 Citation。retained-unresolved 仍保留未解决状态，撤回不提供事实支持；撤回本身不表示流程完成。

当前 Host 可读取按原材料重算的完成状态，并记录包含当时全部依据的不可变历史决定。计算条件与能力限制见 [local Provider](../research-handoff-local/README.md)；状态不代表事实真伪认证。

实际 Driver 回执可以包含一条消息或单个文本附件的身份，以及完整、局部或不可用的回读。当前 Host 可以读取保留的历史，但不因此获得新的提交能力；精确匹配与失败语义见 [local Provider](../research-handoff-local/README.md)。缺失不证明已收到，也不证明未收到。

execute 可以携带可选的可信同步检查函数，用于复核精确请求。该可调用值与日志、持久数据分开，不能恢复人工确认或 Host 访问；调用时机由本地 Provider 负责。底层调用者可以不提供它。

完整流程预览留存精确规范请求、原模板与槽值、材料全文及身份，以及全部前置阶段的动作和交付依据。run 确认与针对精确摘要的人类预览确认分别处理。Host 只把当前已确认预览冻结到固定准备输入 ID，不接纳外部动作。阶段交付门和不可变人工不匹配处置见 [local Provider](../research-handoff-local/README.md)；标准协调器由[流程 Consumer](../research-workflow/README.md)提供。

## 模型体验

### 留存研究记录

#### 模型看到的内容

`researchHandoff`：本 Definition 不注册模型工具或提示词输入。采集输入与有归属的判断属于数据，不能证明事实核验完成。

#### Token 影响

本 Definition 不改变 token 预算，也不自动向外部提交输入。

#### KV 缓存影响

实际模型请求前缀由使用该接口的 Driver 负责；本 Definition 不改变 KV 缓存。

## 已知限制与待实现工作

- 本 Definition 不提供网站传输。Driver 必须使用已观察且受支持的接口，缺少证据时返回 unsupported 或 not observed。版本化提示词准备、逐动作 Session 输入日志及原资源采集提供本地基础；live Agent/Session Host 与固定阶段标准协调器已实现；人类命令/UI 注册及 Loader 应用快照仍待完成。接口测试不证明网站兼容、研究事实核验或收益。
