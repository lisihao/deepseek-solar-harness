# @deepseek-ai/dsh-research-handoff-local

[English](README.md) | 中文

这个私有 SQLite 库记录研究 run 的修订、精确确认、不可变的外部动作输入及目标、只追加的 Driver 观察，以及分版本保留的采集字节。它自身不提交网页或模型请求。

## 动作所有权

问题、来源选择、模式、目的地和计划版本共同形成确认绑定。任何观察修订都会清除旧确认。向 Gemini 提交问题以生成计划，与开始研究是两个外部动作，分别保留输入和目标。

动作意图先以 `unknown` 提交到数据库，然后才调用 Driver。重复动作只读取原记录；输入冲突会被拒绝，未决动作不能通过更换 action ID 绕过。Provider 派生的逻辑阶段身份还会阻止另一个 action ID 在同一 run 修订下重复执行已完成阶段。回调抛错会保留 unknown，并向调用者报告错误。接纳和完成观察保留稳定序号，供投影重建；与终态矛盾的证据会被拒绝。关闭数据库不等于取消远端研究。

每个归属明确的 run 只有一份不可变标准流程定义和规范 Session 身份。领取定义时，在同一事务中留存原问题、明确的平台选择、模板版本、完整槽值及四个阶段身份。相同请求读取原定义；同一 run 的另一 workflow、Session 或输入会被拒绝，新研究必须使用新 run。读取定义仍要求当前所有者能力，外部动作的接纳继续由原动作库负责。

## 完整本地产物与传输

规范输出采集通过 Host 显式提供的可信采集器，只读取已完成的原阶段。每次实际观察都有不可变身份；新的 partial 或 complete 观察追加产物版本，相同观察返回原产物。观察元数据与原产物在同一 SQLite 事务中提交，并与普通采集共用角色版本计数。采集器在读取前检查当前 Host 和原 Driver 注册；已经接纳的调用在撤销后返回时可以保留原材料，但不能据此发起新读取或推进流程。

采集记录在同一 run 数据库中保留传入的全部 UTF-8 字节，以及原动作摘要、页面与会话观察、提取方式、采集时间和独立的 complete/partial/unknown 范围。complete 采集必须附有明确的报告结束证据；这不会改变动作处理状态，也不表示事实核验完成。新版本按产物角色追加，不覆盖旧字节；并发提交的过期版本会被拒绝。人工导入仍然只是中间采集方式。

分块前必须按 owner 授权读取产物，知道 SHA-256 标识不能取得读取权限。明确的字节预算生成按顺序排列的 UTF-8 分块，记录字节区间、分块数、各块摘要和完整摘要。还原时拒绝缺块、重复、乱序或内容变化，并保留原字节顺序标记和换行。本地完整性不能证明网站收到这些分块或模型理解了它们；实际提交消息与附件的观察关系仍需上层 Provider 和 Driver 实现。

## 版本化提示词与完整准备输入

包内包含四份原 research-design 材料，并固定原字节摘要。其中历史研究依据作为来源材料保留，不作为当前账户或产品能力的观察。两个 v1.0 模板要求显式提供全部命名槽位。渲染只在原模板中替换一次，保留插入文本中类似槽位的内容，拒绝有损 UTF-8，且不截断。缺失事实必须由 Host 明确填写，渲染器不补默认值。

Host 在动作之前留存原模板、全部槽位内容、完整渲染文本及摘要。产物段必须经过按所有者授权读取，并匹配不可变字节和版本。原问题必须匹配 run 绑定。准备输入不会确认 run。同一准备身份不能改变内容；动作引用它时，必须在 unknown 意图提交前匹配 run 修订、原问题、全文及阶段。恢复读取保留旧输入，不重放动作。直接 Host 文本仍是显式的底层路径，完整流程 Consumer 必须选择准备好的模板。留存不能证明实际提交消息或附件已收到；Session 适配器与实际动作交付历史提供日志和映射基础；完整流程及 UI 装配仍是独立工作。

## 候选分母与判断

候选目录绑定问题摘要和不可变报告版本。每个发生变化或退出目录的候选项都保留父子身份与理由。拆分、合并、删除、修订或降低主张重要性会追加新目录，不能继承旧分母确认。确认必须由独立的可信控制调用执行，并匹配当前目录、run 修订及两个阶段最新报告的完整采集记录；新的报告字节会使旧确认失效。

有明确归属的模型或人工判断按顺序追加，不覆盖旧判断。材料引用只标识保留的输入，不表示已独立用浏览器回源读取。导入内容中的确认、完成和覆盖率字段被排除。确认分母或出现 `supported` 判断都不能证明事实已核验、来源确实支持主张或综合已完成。上层 Provider 必须从实际输入通道确定判断归属。

首次实际 Driver 资格结果在 Provider 复查授权或提交之前，按完整原动作摘要留存。恢复读取会保留观察到的设置、推理力度是否可观察、完整输入容量、明确不可用状态、证据及本地收到结果的时间。缺少回执时仍然缺失，不从请求设置补造结果。改写已留存观察、其他所有者读取或损坏的持久字段会被拒绝。

判断内容保留其声明的 by 字段，独立且不可变的归属记录由当前 Host 策略提供通道、所有者和策略版本。导入的归属与完成字段不能替代它。这属于同进程宽信任域中可信嵌入 Host 的声明，不是独立的人工在场证明；UI 和模型 Consumer 仍须选择各自正确的 Host 通道。

## 来源读取与未决操作

来源读取意图与精确 URL 的未决检查在同一 SQLite 事务中提交。更换读取 ID、run 修订或 Reader 不能绕过 unknown 或 accepted 的原读取；另一精确 URL 可以继续。完整请求不可改变，异常保留未知状态。只有明确发生在访问前的拒绝才能记为 not-admitted。持久检查记录只说明该时点获准，不表示实际访问已经发生。

首次访问及每次跟随重定向前，均重新检查当前 Host 回调、原请求、当前修订与同一 Reader 注册。撤销后的实际迟到接纳仍归原读取。观察只能检查已关联资源；没有资源时直接返回原未知记录，不调用 Reader。捕获保留全部提供的 UTF-8 字节，并分别记录全文、相关段、搜索摘要、仅标题、不可访问和未观察到；这些范围不能证明语义支持。关闭等待受持有调用结束；适配器永不返回时可以持续等待。

## 工作流记录

本地 Provider 实现研究 Service Definition，使用当前 Host 注册与显式注册的 Driver。它检查按所有者隔离的访问、包含推理力度的完整选择、来源配置、原目的地和全部输入的容量。资格检查在 unknown 意图提交之后执行；Driver 必须在提交前立即再次检查当前授权。撤销阻止新工作，但允许记录有明确关联的迟到接纳。Provider 处置会先等待其拥有的调用结束，再关闭 SQLite；Driver 永不返回时，处置可能无限等待。

嵌入流程 Host 可以为同一 grant 添加可信 live 归属检查。持久访问及既有提交、来源和采集器 guard 均调用它，回调后再次检查 grant。回调不能恢复旧 grant，也不能把已存 ID 变成权限。不提供该可选检查时保留原始 Host 行为；完整流程入口和 Agent 注册归属由 Consumer 负责。

私有预发布数据库使用版本 19，旧版本和不支持的格式会被拒绝，不自动迁移。不可变的原目标与实际观察到的新会话、报告身份分别留存。非空身份不能改变；accepted 观察可以补齐未分配字段，completed 终态事实不能替换。

每次首次提交前，检查函数会重新读取当前 run 修订、完整确认摘要及确认状态，并检查原动作仍为 unknown。计划修订或已经观察到完成会阻止尚未提交的操作。提交后收到的实际接纳仍归原动作及原修订。execute 与 observe 合并已有证据后都必须有资源关联；持久记录为 accepted/completed 却没有资源时拒绝读取。

来源捕获分别记录读取范围与 complete、partial、unknown 完整性；不完整或未知时必须保留限制说明，正文摘要不能替代该状态。run 修订不会单独阻止观察已关联的原资源，但观察仍检查当前 Host、Reader、来源配置和原目标授权；它不打开新页面，也不重新读取原 URL。

引用判断绑定精确目录摘要、当前论断文本摘要、原来源读取和规范化观察摘要。非空短引必须逐字节匹配留存全文或相关原文段中的完整 UTF-8 区间；仅 URL、搜索摘要或标题不能满足实际原文要求。捕获完整性仍独立，后续完成逻辑必须另外检查。引用关系、来源家族依赖和原始权威记录的分类仍是有归属判断；声明的模型或人工作者与当前 Host 的实际输入通道分别记录。响应以追加方式保留，不能删除反证；该记录不产生独立支持计数、事实正确保证或核验完成标志。

反证处置绑定原 Citation 或材料判断的完整记录摘要、历史目录和论断文本。针对同一原目标的处理以 CAS 追加，保留所有历史，允许明确重新保留未解决状态；追加另一条 supported 引用不会改变处置。explained 需要实际 Citation；corrected-in-final 使用 Citation 或明确的 finalCorrection 映射依据，仍属于有归属解释，不是自动语义裁定。声明的作者与当前 Host 输入通道分别持久化；导入完成字段不能授权或解决反证。处置记录本身不提供最终报告映射或当前核验完成状态。

最终映射在同一 SQLite 数据库中追加，绑定精确 run 修订、原问题、当前目录及最新完整 Gemini/ChatGPT 报告身份。记录保留全部最终正文，校验 UTF-8 原文位置、候选覆盖、当前文本 Citation 关联、依赖存在性并拒绝依赖环。退出的历史关键候选保留真实变更谱系及最终报告修订位置，无替代项也不例外；旧错误文本不需要得到 supported。实际 Host 通道归属与声明作者分别记录。同一映射重试不可变，同一 run 后继映射使用 CAS。Host 另行确认精确最新映射和已确认分母；最终关键采用事实为零时必须说明适用理由。历史确认保留，新映射、报告、目录或 run 修订会改变其当前有效性。确认仍可保留未完成反证检查及未解决处置，不表示核验完成。

finalCorrection 只用于精确历史目标的 corrected-in-final 撤回依据。追加与当前已确认映射的校验在同一事务内进行，必须匹配 retired 的目录版本、claimId、原文摘要及报告修订位置，最终所有 adopted-fact 均不能继续采用该原文摘要。映射先存在，处置随后追加；当前映射不必反向列出新处置 ID。历史读取保留固定映射关联，新映射或报告之后不能把旧撤回依据当作当前依据，也不回退到无关 Citation。retained-unresolved 仍保留未解决状态，撤回不提供事实支持；撤回本身不表示流程完成。

readFinalStatus 在同一 SQLite 快照内重算流程完成状态。缺少留存的原问题全文或必要完整报告时返回 needs-input；完整报告已存在但映射缺失、过期或未确认时返回 partial。每个最终关键项目均作为依赖闭包起点，闭包中的每个采用事实都必须有针对当前文本的 supported Citation，并关联完整的全文或相关原文段捕获。关键反证检查未完成或精确目标反证未解决时阻断完成。历史关键删除即使没有替代项，也保留精确报告修订位置；撤回不提供事实支持。明确的条件假设和零事实适用理由不产生百分比或事实正确保证。

recordFinalDecision 仅通过当前 Host 接收新决定身份，在同一事务内保存计算状态、全部已用规范化记录、身份、版本、摘要及实际输入归属。同一身份再次调用保留原结果。历史读取校验留存 JSON 和摘要，另行重算 isCurrent；新增反证、重新保留未解决状态，以及报告、目录、映射或修订变化，都不能被旧完成决定遮蔽。普通限制与所需依赖闭包之外尚未核验的非关键事实仍可见。来源独立性、分类及语义充分性仍是有归属判断；留存问题与材料链不证明实际定向或穷尽检索。

交付记录共用同一 SQLite 所有者，但在原动作接纳事务之后单独提交。映射格式错误、外部身份变化或映射写入失败，不能回滚已 accepted 或 completed 的动作事实；重试也不重新提交原动作。精确的后续观察可以为已经 completed、动作事实未变的记录补充映射。历史资源字段允许从 null 补齐；非空身份，以及同一 run/action/kind 的外部身份均不能替换。

完整 UTF-8 回读与原动作全部输入逐字节比较，不做规范化、去空白，也不用摘要代替。完整文本产生 matched 或 mismatched；局部预览或无法读取的内容产生 not-read-back。不匹配与后续匹配都保留在有序历史中。观察到外部 ID 不证明字节相同、模型理解或事实正确。这里的附件仅限单个 UTF-8 文本文件，不支持二进制、PDF、多附件或分段交付。标准采集产物至动作的关联另行校验；完整两阶段入口仍由 Consumer 实现。

可选的请求专属 guard 在创建动作前、资格检查前、资格返回后，以及 Driver 实际 I/O 前的检查点执行。每次调用取得同一实际请求的独立副本，返回后再次检查当前 Host。最终请求检查拒绝推进前，迟到接纳与交付事实已经留存。创建动作之前失败不会占用固定动作 ID；unknown 意图之后失败不会释放该 ID 供重放。

流程预览及其独立确认与原动作共用 SQLite 所有者。创建或读取预览不占准备输入或动作 ID。读取使用同一数据库快照；材料角色的新版本、run 修订或冲突的已冻结输入会使当前预览失效，历史不改写。确认要求准确 run 已先确认、完整预览摘要匹配，并通过当前可信人类入口检查。冻结在同一事务复核这些条件后写入原准备提示词，不嵌套 BEGIN，也不提交外部动作。旧 schema 1–18 拒绝且不迁移。

标准预览只绑定前置阶段已完成的原动作、规范采集材料、完整交付历史和精确人工处置。开始研究之前要求 Gemini 计划消息全文匹配；上传之前要求完整采集的原研究报告；提交核验之前要求原上传已完成，且原 ChatGPT 会话中的附件全文匹配。核验消息在提交后另有全文匹配门。普通导入产物或较新的 partial 角色版本不能替代当前完整规范输出。完整模板、槽值、产物 ID/版本/摘要/全文和原目标关联分别校验，不由动作 completed 代替。

同一外部项目后续的完整匹配可以补足 not-read-back。每条 mismatch 持续阻断，直到当前可信人类入口针对全部精确负面序列，以更晚的同项目全文匹配和明确理由作出处置。处置按同动作 CAS 追加，保留原动作、材料、完整历史及实际归属。新 mismatch 或原材料变化使其当前用途失效；新增正面或无法读取的观察不抹除负面记录，也不改写历史快照。预览确认保留精确预览摘要。动态预览检查在接纳动作之前及异步等待之后拒绝已变化的前置条件；已经观察到的事实仍由原动作所有者保存。这些检查不证明网站兼容、模型理解或语义正确。

readWorkflowState 在同一 SQLite 读取快照中计算原动作、当前完整规范输出、全部留存预览、完整交付历史及既有最终核验状态。输入全文交付、可进入核验和有归属的最终核验分别呈现。即使完整报告已存在，未完成的标准链也不能继承底层已完成核验状态。标准阶段预览选择原模板与规范材料，只在绑定变化时修订 run，不确认或执行动作。

## 模型体验

### 留存研究记录

#### 模型看到的内容

`LocalResearchHandoffService`：本地 Provider 为当前 Host 留存完整动作输入与产物，不注册模型工具或提示词段。

#### Token 影响

本包不改变模型请求或 token 预算，完整输入会增加本地存储。

#### KV 缓存影响

此存储 Provider 不改变模型请求前缀或 KV 缓存。

## 已知限制与后续工作

- 这仍不是完整研究能力。Session 适配器已提供逐动作完整输入日志和留存事实投影；固定阶段标准 Consumer 已另行实现；实际网站 Driver、UI 注册及真实 Loader 应用快照仍待完成。fake Driver 测试不证明网页采集完整性、回源核验、账户可用性或研究收益。
