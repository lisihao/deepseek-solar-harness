# @deepseek-ai/dsh-task-template-context

[English](README.md) | 中文

任务提示词模板的直接 Agent Consumer。它使用确定性规则分类当前用户请求，通过 `ctx.taskTemplates` 选择模板，并追加一条带来源的 user 角色指令；其回执保存精确的已选内容。

## 注入时机

模板按逻辑用户任务选择一次，而不是每隔固定轮次重复注入。带来源消息会保留在 Session 表层，因此只要该历史仍被保留，后续无状态模型请求都会继续携带它，但 Session 不会追加副本。新的用户请求会重新选择。TaskGraph 节点与 Debate 角色是彼此独立的逻辑任务，会在各自分发边界单独选择；一次性算子与 Web 算子的每次独立分发都会收到完整的已选上下文。

工具循环步骤、传输重试与 Resident 轮询都不会重新选择或追加模板，而是复用已记录回执或密封的算子上下文信封。压缩可能用摘要替换早期消息；DSH 不使用周期性重注入计时器，因为固定间隔会在操作中途重复指令，并在没有任务边界的情况下改变行为。

推断覆盖常见研究、洞察报告、架构、审查、规划、编码、写作、前端、后端、基础设施、金融、法律、智能体系统、输出格式、风险、语言和紧急信号。推断出的风险仅是路由元数据，绝不构成操作授权。

## 模型体验

#### 模型看到的内容

所选方法、偏好与记忆位于一个 JSON 框定的 `dshTaskPromptTemplate` 文档中。该框架明确声明当前用户请求与系统安全规则具有更高优先级。

#### Token 影响

每个逻辑任务新增一条消息。无状态 API 会在后续步骤重发保留历史，但该消息可复用前缀缓存，且不会在 Session 中重复累积。

#### KV Cache 影响

只在任务边界追加。新任务重新选择时只改变新的尾部。

## 已知限制与后续工作

- 分类依赖维护的关键词表；模糊任务可能只能匹配宽泛模板。
- 直接 Agent Consumer 尚无显式模板选择器；程序化 TaskGraph Consumer 可以密封显式模板 ID。
- 压缩依赖摘要保留仍相关的指导；尚无感知回执的压缩后重新锚定机制。
