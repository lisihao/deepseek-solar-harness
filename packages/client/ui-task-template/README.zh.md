# @deepseek-ai/dsh-client-ui-task-template

[English](README.md) | 中文

任务提示词模板库的设置页 Consumer。它通过经认证的 `/task-templates` RPC 通道展示 Server 权威模板目录、方法编辑器、逐字段匹配说明、启停状态、修订数量、独立的个人偏好／记忆字段，以及已保存模板的渲染预览。

新建模板默认停用，因此未完成的方法在用户明确启用前不会参与选择。

编辑器不会把私有内容写入浏览器存储或源码配置。Remote Frontend 切换连接目标时，页面会先清空当前模板库和编辑器，再读取所选 Server 的 DSH 私有主目录；之前权威返回的响应无法重新填充页面。

一次保存可能分别修改方法、启停状态和个性化内容。UI 会立即采用每次返回的权威快照；如果后续修改失败，已提交的修改会继续显示，剩余草稿可供重试。

## 模型体验

### 模板管理

#### 模型看到的内容

本浏览器包不会直接产生模型请求内容。保存操作会修改私有模板数据；`@deepseek-ai/dsh-task-template-context` 可能在后续逻辑任务中注入这些数据。

#### Token 影响

加载、编辑、保存和预览不会直接增加 token，也不会调用模型。只有 `@deepseek-ai/dsh-task-template-context` 选中模板时，保存内容才会影响后续请求。

#### KV Cache 影响

这些设置操作不会修改进行中请求的前缀。修改保存内容后，后续任务选中该模板时，其注入前缀可能改变。

## 已知限制与后续工作

- 匹配值目前使用逗号分隔文本框，而不是带目录的标签选择器。
- 页面会显示修订数量，但尚不能比较或恢复历史修订。
- 预览只渲染最近保存且已启用的版本；新建、停用或已编辑的草稿必须先保存并启用。
